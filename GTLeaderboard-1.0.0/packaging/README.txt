GTLeaderboard 1.0.0 · Windows x64

처음 사용
1. full.zip을 새 폴더에 모두 압축 해제합니다.
2. GTLeaderboard.exe를 실행합니다. Python 설치는 필요 없습니다.
3. OCR에 필요한 models 폴더는 실행 파일 옆에 그대로 둡니다.
4. 저장·Ctrl+S는 편집 데이터가 포함된 PNG로 저장합니다.
   새 파일 저장은 PNG 미리보기에서 해상도를 확인한 뒤 저장합니다.
5. 내보내기의 GTLB로 저장 / CSV로 저장에서 각각 전체 데이터 / 표시 내용만 만듭니다.
   CSV는 순위표와 하단 배점 안내를 포함하며 원문·이력·ID는 제외합니다.
   내보내기 후에도 편집한 원본 PNG는 별도로 저장해야 합니다.

라운드 관리
라운드 결과 → 라운드 관리에서 위·아래 이동과 삭제를 사용할 수 있습니다.
변경 적용 후 PNG를 저장하세요. 관리 창의 취소는 이동·삭제를 모두 되돌립니다.

업데이트
앱의 도움말 → 버전 · 업데이트에서 새 버전 ZIP을 선택하고
새 버전 폴더를 만들 위치를 고릅니다. 전체(full) ZIP과 모델을 제외한
update ZIP 모두 지원합니다. update ZIP은 기존 모델을 검사해 복사합니다.
현재 리그를 저장하고 앱을 종료한 다음 새 폴더의 실행 파일을 실행하세요.
새 앱에서 기존 리그 파일을 직접 열면 됩니다. 리그 파일은 이동하지 않습니다.
0.5.0 이하에는 업데이트 메뉴가 없으므로 전체 ZIP을 직접 압축 해제하세요.

기존 폴더와 저장 파일은 덮어쓰지 않습니다. 이전 버전으로 돌아가려면
기존 실행 파일을 사용하세요. 향후 저장 형식이 바뀌는 버전에 대비해
새 버전으로 저장하기 전 리그 파일의 사본을 보관하는 것을 권합니다.

실수 복구와 시작 안내:
- 편집 메뉴에서 반영한 작업을 실행 취소/다시 실행할 수 있습니다.
- 라운드 변경 이력에서 이전 결과를 새 개정으로 복원할 수 있습니다.
- 비정상 종료 후 미저장 리그와 메인 라운드 입력을 복구할 수 있습니다.
  OCR 확인 창 내부의 미반영 수정은 복구 대상에 포함하지 않습니다.
- 첫 화면에서 새 시즌 만들기와 최근 리그 열기를 사용할 수 있습니다.
- PNG 저장 후 저장 폴더 열기로 파일 위치를 확인하세요.
- 업데이트 준비 후 현재 리그 저장 후 새 버전 실행을 누르면 이어서 열립니다.

업데이트 주소는 GTLeaderboard 저장소의 main/update_manifest.json Raw 주소로 고정됩니다.
주소 변경 입력란은 없으며 이전 사용자 지정 주소 설정도 무시합니다.
시작 시 GitHub에서 새 버전을 자동 확인합니다. 도움말 → 버전 · 업데이트에서
변경 사항을 보고 다운로드 · 업데이트 준비를 누르세요. 자동 확인은 해제할 수 있습니다.
다운로드한 ZIP은 크기·SHA-256·내부 버전을 검사합니다. 새 버전은 별도 폴더에 준비됩니다.
카페와 GitHub에 게시된 같은 버전의 ZIP을 모두 사용할 수 있습니다.
현재 실행 파일은 코드 서명이 없어 Windows에서 확인 창이 나올 수 있습니다.

SOURCE.zip에는 앱 소스와 재빌드 방법이, licenses에는 제3자 고지가 있습니다.
OCR은 CPU에서 로컬로 실행되며 스크린샷을 외부로 전송하지 않습니다.
